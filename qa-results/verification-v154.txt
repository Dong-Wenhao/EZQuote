## 开发复现

    python -m pip install -r requirements-dev.txt
    python -m pytest tests independent-results retest-results -q
    npm install
    node tests/extension_checks.mjs

设置 TEST_PYTHON 和 BROWSER_EXECUTABLE 为实际 Python、Chrome 可执行文件路径，再顺序运行上表各脚本，例如：

    node tests/copilot_browser.mjs
    node tests/ui_polish_browser.mjs

这些脚本共用 8765/8766 端口，不可并行启动。普通用户启动程序不需要 Node。Windows PowerShell 使用 $env:TEST_PYTHON 和 $env:BROWSER_EXECUTABLE 设置路径。

## 实现边界与实机待验

- 没有执行 Windows 干净环境首次安装、双击 BAT 和 Chrome 原生扩展安装。没有登录真实 WhatsApp；真实 DOM、聊天绑定及草稿回填需本机试用。
- 真实模型、Meta 权限、真实手机收件和公网隧道未联调。通知相关测试使用合成提供者，手机网关仅为真实本地 HTTP；默认外部连接关闭。
- 需求整理是常见建材表达的本地规则，历史建议是统计与店铺规则。复杂或未理解内容仍须人工确认或分行改写。
- 库存是导入快照，不预留、不出库；客户成交人工登记。回复由人发送，PDF 单独附加。
- 本轮不新增数据库表、不改变 v5 核对格式、不改已批准报价快照。升级保留 data 和 .venv；各电脑数据独立。

历史修复及升级证据保留在各版本说明和 qa-results；当前验收以本文件与 1.5.4_优化与验收说明.md 为准。
