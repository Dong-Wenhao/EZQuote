EzQuote MVP 1.6.1

Read 队友使用指南_1.6.docx first.
If an older version is installed, first read 更新到1.5_先看这里.md and keep the original data and .venv directories.

Starting on Windows:
1. Extract the complete package and open the directory containing run.py.
2. Enter cmd in the File Explorer address bar, press Enter, then run python run.py.
3. Keep the terminal open and visit http://127.0.0.1:8765/.
4. New users set owner and staff passwords; the owner imports samples/business_demo.xlsx.
5. Load the extension directory in Chrome developer mode and confirm version 1.6.1.

If complete business data is already present, there is no need to import it again. Older unapproved business quotations must be reviewed again and saved as new revisions.
When manually changing quantities, removing products, or changing delivery, enter a reason and review again as prompted.
For 20／30, first ask for the final quantity; 1_020 will not be truncated to 20. Supply details for unknown products, or record a reason if they are canceled.
This release uses no API. Keep real AI and automatic mobile notifications disabled. A person checks and sends customer replies.

The updated interface shows review progress and a character count. Each request supports up to 40 product requirements. If prompted that the input is too long, submit it in batches while retaining specifications, quantities, and delivery details.
See 1.6_界面更新说明.md for the current page layout and 1.6.1_最终交付检查.md for final acceptance records.

The 1.6 series uses dark green and mint green. Wide desktop windows use left navigation, while the sidebar and mobile interface use compact layouts; the original quotation workflow and data remain in use.

If startup reports Port 8765 is already in use, close the old service terminal and start the new version again. Do not delete data or .venv.
See 1.6.1_最终交付检查.md for the final delivery checks.
