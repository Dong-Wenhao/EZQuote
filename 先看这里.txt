EzQuote MVP 1.6.1

先读 队友使用指南_1.6.docx。
已安装过旧版，先读 更新到1.5_先看这里.md，保留原 data 和 .venv。

Windows 打开方式：
1. 完整解压，进入能看到 run.py 的文件夹。
2. 文件管理器地址栏输入 cmd，回车，运行 python run.py。
3. 保持窗口打开，访问 http://127.0.0.1:8765/。
4. 新用户设置老板和员工密码；老板导入 samples/business_demo.xlsx。
5. Chrome 开发者模式加载 extension 文件夹，确认版本 1.6.1。

已有完整经营数据不必重新导入。旧的未批准经营报价要重新核对并保存新版本。
人工改数量、删商品、改配送时，按页面提示填原因并重新核对。
20／30 要先问清最终数量；1_020 不会截成 20。未知商品需补充，取消需记录原因。
本次无 API，不要开真实 AI 或手机自动通知。客户回复由人核对后发送。

新版显示核对进度和字符计数。每次最多 40 条商品需求；提示内容过多时，请保留规格、数量和配送信息后分批提交。
当前页面布局见 1.6_界面更新说明.md，最终验收记录见 1.6.1_最终交付检查.md。

1.6 系列采用深绿与薄荷绿配色。电脑大窗口使用左侧导航，侧栏与手机使用紧凑布局；原报价流程和数据继续使用。

启动提示 Port 8765 is already in use：关闭旧服务命令窗口，再启动新版。不要删除 data 或 .venv。
最后一轮交付检查见 1.6.1_最终交付检查.md。
