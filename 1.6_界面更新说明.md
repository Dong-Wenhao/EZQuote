# EzQuote 1.6.0 Interface Update

This document records the interface introduced in 1.6.0. The current delivered version is 1.6.1, which also includes startup fixes. See 1.6.1_最终交付检查.md for the final checks.

Following the reference image supplied by the team, this round adopted a dark-green sidebar, a light gray-green page background, white content cards and mint-green emphasis areas. Branding is consistent as EzQuote. Pages continue to use the existing product, review, pricing and approval workflows.

## Colors and Layout

| Area | Changes in this version |
| --- | --- |
| Navigation and branding | Dark-green #084c3c sidebar, green #08835d action buttons, EZ icon and EzQuote name |
| Pages and cards | Light gray-green #f4f8f6 background, white cards, fine borders, consistent corner radii, spacing and type sizes |
| Amounts | Original and recommended amounts shown side by side; recommendations use a mint-green background and green digits |
| Status | Pending review is yellow, approved/passed is green, and returned or lost is red; text labels remain |
| Desktop home | Overview, actual pending/follow-up/all counts and recent quotes; workflow guidance appears alongside them on wide screens |
| Products and quotations | Original text, specifications, quantities and review notices remain step-based; wide-screen quotes separate the summary and amounts into columns |
| WhatsApp side panel and mobile | Green theme, compact top navigation and a vertical layout; the message entry point and mobile approval use matching colors |

The desktop sidebar appears from 900px; narrower screens use top navigation. From 1100px, the home page shows recent quotes and workflow guidance in two columns. Narrow screens hide supplementary workflow explanations while retaining every actual operation. The new desktop “New quote” shortcut enters the existing workflow directly. Settings remain owner-only, and workspace navigation is hidden after logout.

Unimplemented customer-management, reporting and sending-status menus from the reference image were not added. Its example amounts and conversion rates were not reused either. The home page shows actual quotation statistics accessible to the current account. Quote approval and customer purchase continue to be recorded separately.

## Verification

- All existing 329 backend and independent tests passed in 38.25 seconds, with 1 existing compatibility deprecation warning.
- All 64 groups across nine browser scripts passed. The interface script expanded from four groups to six, adding actual desktop navigation, role restrictions, green-theme resources, six-width responsive behavior and hidden navigation after logout.
- Extension logic: 10 groups passed.
- Home pages in Chinese, English and Malay were checked at 320, 430, 768, 900, 1160 and 1440px without horizontal overflow. Quote amounts at 320, 430 and 1160px had no horizontal overflow or clipped amount cards.
- Actual local approval, owner price adjustments, PDF, Excel, customer feedback, late-response isolation and mobile-gateway checks continued to pass. The default remained no-API mode.
- The Chinese desktop home page, quotation page, owner approval, narrow-screen product page, Malay 320px home page and mobile approval were visually inspected. The two-page Word guide was updated and checked page by page.

White text on primary buttons has a contrast ratio of approximately 4.76:1; secondary body text against the page background is approximately 4.65:1. These checks cover selected color combinations and do not certify accessibility for every component. Wide and narrow layouts retain keyboard-focus indicators, selected navigation uses aria-current, and statuses retain text labels.

The test environment used Linux, Chrome Headless Shell 140, a real local HTTP backend and a local mobile gateway. The packaged font was installed in the test environment for Chinese screenshots. Native Windows installation, real Chrome extension permissions and real WhatsApp account integration were not tested; no paid API was called and no real mobile notification was sent.

## Updating

Stop the old service and back up the project. Replace the original project files with the new package contents while preserving data and .venv. Restart the backend, reload the current extension at chrome://extensions, confirm version 1.6.1, then refresh WhatsApp and the local workspace.

This round adds no database tables and does not change approved quotes, PDFs or the review-digest format. Models and automatic mobile notifications remain disabled by default. Replies still require human checking and sending, with PDFs attached separately. Instructions are in “队友使用指南_1.6.docx”, complete logs are in qa-results, and developer commands are in VERIFICATION.md.
